# Дизайн лендингов Coral Club: правила для Claude

Этот файл можно целиком вставить в Claude (Claude Code в клоне репозитория, либо в начале нового чата). Он описывает, как собирать новые лендинги в нашем дизайне **из готовых компонентов**, а не рисовать с нуля. Если что-то в файле расходится с кодом, прав код: сверяйтесь с `src/styles/tokens.css` и `src/components/`.

Репозиторий: `bogdan787878/coralclub` (Next.js 16, App Router, статический экспорт, TypeScript, CSS Modules без UI-фреймворка). Примеры целых лендингов: `src/app/landing/` (русский лендинг «Система красоты»), `src/app/friend/` (проект «Друг клуба»), `src/app/(shop)/v2/` (главная одной фазы).

## 0. Как работать

1. Новый лендинг — новая папка маршрута `src/app/<имя>/` (+ `layout.tsx`, если нужен свой рантайм) и свои компоненты в `src/components/<имя>/`. Существующие страницы не трогать.
2. Сначала посмотрите, нет ли готового компонента (разделы 4–5). Новый компонент пишите только если готового нет, и стройте его на токенах (раздел 3).
3. Перед кодом прочитайте `AGENTS.md`: версия Next.js здесь нестандартная, API сверяйте с `node_modules/next/dist/docs/`.
4. Запуск: `nvm use` (Node 20), `npm install`, `npm run dev` (http://localhost:3100). Проверка: `npm run lint` и `npm run build` без ошибок.
5. Не создавайте реальных заказов и аккаунтов в магазине (coralclub.ru), не меняйте `.github/workflows`, секреты и ключи в репозиторий не кладите (он публичный).

## 1. Характер дизайна

- Спокойный и светлый: белый фон, нейтральные серые подложки `#f6f6f6`, один тёмный бирюзово-зелёный акцент (малахит). Ярких цветов, градиентов и тяжёлых теней нет.
- Крупные скругления: карточки и блоки с фото — `32px`, поля и кнопки-«таблетки» — `pill`, мелкие элементы — `8–12px`.
- Фото большие и показываются целиком (без обрезки и без наложения текста поверх, кроме hero на мобильном).
- Заголовок = **«прямой» шрифт + курсивный акцент** одной-двумя словами: `Почему наша <Accent>система работает</Accent>`.
- Мало текста: заголовок, 1–2 абзаца, действие. Объяснять механизм, а не хвалить.
- Один основной призыв на экран; кнопка тёмная (малахит), на тёмных блоках — белая.

## 2. Верстка: основа

- Mobile-first. Контрольные ширины: **390** (телефон), **768**, **1024+** (веб), 1440.
- Контейнер: `<Container>` (боковые отступы 16, ширина растёт: 480 → 720 → 960 → 1200 по `--container-max`; от 1024px сама оболочка `.appShell` без ограничения).
- Страница: `<div className="appShell"><main>…</main></div>`.
- Вертикальный ритм блоков: на телефоне `56px` сверху/снизу, на вебе `112px` (hero `32–40px`, футер компактнее).
- Сетки карточек: на вебе **4 колонки, зазор между колонками 24px, между рядами 64px** (переменные `--carousel-col-gap` / `--carousel-row-gap` на обёртке), на телефоне горизонтальная прокрутка с «подглядыванием» следующей карточки.
- Hero на вебе: два столбца (текст 4fr + фото 9fr), максимум 1920px, фото со скруглением; на телефоне фото сверху, текст под ним.
- Не задавайте цвета, размеры и отступы «числами из головы»: только токены или значения из этого файла. Исключение — подгонка размеров логотипов и иконок.

## 3. Токены (`src/styles/tokens.css`)

**Цвета**

| Токен | Значение | Где |
|---|---|---|
| `--color-text` (= `--color-malachite-100`) | `#002022` | текст, заголовки |
| `--color-malachite-90` | `#004144` | кнопки, тёмные блоки, акцент |
| `--color-malachite-70` | `#007d79` | вторичные акценты, «ок»-текст |
| `--color-malachite-30 / -20 / -10` | `#92cbca / #bededd / #e3f7fa` | светлые подложки |
| `--color-neutral-30` | `#f6f6f6` | подложки карточек и секций |
| `--color-text-muted` | `rgba(0,32,34,.6)` | второстепенный текст |
| `--color-text-on-primary` | `#fff` | текст на тёмном |
| `--color-special` | `#cb8d52` | бежевая метка скидки −20% |
| теги «для чего продукт» | `#a2d24a` | зелёный текст над названием карточки |

**Типографика:** основной шрифт Suisse Intl (`--font-sans`), акцент Newton italic (`--font-accent`, через `<Accent>`). H1 28/32 → 48/52 на вебе (`--text-h1-*`), H2 28/32 → 34/40 (`--text-h2-*`), текст 14/20 (`--text-body-long-*`), кнопка 16/24 (500).

**Отступы:** `--space-4/8/12/16/20/24/32/40/48/64`; `--page-padding-inline` 16, `--page-padding-block` 32, `--gap-base` 24, `--gap-text` 16.

**Радиусы:** `--radius-sm` 8, `--radius-md` 12, `--radius-base` 32, `--radius-pill`. **Анимации:** `--ease-standard`, `--duration-fast` 120мс, `--duration-base` 200мс; всё, что движется, отключайте под `prefers-reduced-motion`.

## 4. Готовые компоненты

Импорты: `@/components/ui` (примитивы), `@/components/organisms` (блоки), `@/components/landing` (то, что сделано для лендингов).

**Примитивы** (`ui`)
- `Container`, `Section` (`tone="default | surface | primary"`: белый / белый / тёмно-зелёный; серую подложку делайте классом `background: var(--color-neutral-30)` с повышенной специфичностью), `Stack`.
- `Heading` (`as="h1" | "h2"`), `Accent` (курсив), `BodyLong`.
- `Button` (`variant="primary | secondary | ghost"`, `block`, с `href` рендерится ссылкой). `secondary` — белая, для тёмных фонов.
- `Accordion` / `AccordionItem` (нативный `<details>`), `Chips`, `Sheet`, `Rating`.

**Блоки** (`organisms`)
- `Hero` — `title`, `body`, `image: {desktopSrc, mobileSrc, alt}`, `cta: {label, href|onClick}`. Одна кнопка.
- `Carousel` — карусель/сетка карточек: `label`, `maxCols`, `minCols`, `stretchFew`, `itemWidth`.
- `ProductCard` — карточка товара: `title`, `tag` (зелёный текст «для чего»), `category`, `price`, `priceWas`, `priceTag` ("−20%"), `href`, `images[]`, `fluid`, корзина: `onAddToCart`, `cartQty`, `onSetQty`.
- `BuyBox` — цена + «В корзину» / степпер (на мобильном приклеен к низу, на вебе плашка сверху: `pinned`, `top`).
- `Editorial` — заголовок, картинка целиком, текст, метка на картинке (`badge`).
- `AdvisoryBoard`, `CommunityReels`, `InfoAccordion`, `FullDescription`, `PeriodicElements`, `ImageSlider`, `SiteFooter`.

**Для лендингов** (`landing`)
- `LandingHeader` — только логотип; `CoralClubLogo`.
- `LandingCards` — карусель карточек каталога (теги, цены, корзина, аналитика).
- `LandingCartButton` — плавающая корзина + шторка (русские подписи); логика корзины в `@/lib/cart` (`addItem`, `setQty`, `useCart`).
- `LandingCta` + `LeadModalProvider` — кнопка, открывающая форму заявки; `LeadForm` — сама форма; страница-форма `/landing/consultation/`.
- `Certificates` — блок «Производство мирового уровня, подтвержденное сертификатами» (логотипы в «таблетках»).
- `Reviews`, `LandingGallery`, `ProductSlider`, `ShowWhenScrolledPast`.

Тексты и цены каталога русского лендинга: `src/lib/landingCatalogRu.ts` (артикулы coralclub.ru, клубная цена `priceRub.club`, обычная = клубная × 1,25, баллы `LANDING_BONUS`). Формат цены — `formatRub()` («3 010 ₽»).

## 5. Рецепт лендинга

Порядок экранов (берите то, что нужно задаче):
1. `LandingHeader`
2. `Hero`: одно обещание + одна кнопка
3. Блок «почему это работает» + информация о скидке/условиях (плашка `--color-malachite-90`, текст 18px)
4. Карточки продуктов (`LandingCards` или `ProductCard` в `Carousel`)
5. Блоки по темам: `Editorial` или «картинка + текст + карточки»
6. `Certificates`, отзывы (`Reviews`)
7. Блок консультации: заголовок, одна фраза, `LandingCta`
8. Футер с юридической сноской
9. `LandingCartButton` в конце `<main>`

Карточка товара: название «Продукт – форма выпуска», зелёный тег «для чего» (одно–два слова, без медицинских обещаний), цена клубная + зачёркнутая обычная + метка «−20%», корзина-иконка в углу фото.

## 6. Тексты

- Русский, на «вы», коротко, без восклицательных знаков и «чудо-обещаний».
- **Без медицинских заявлений**: не «лечит/излечивает/детокс/иммунитет», только состав по этикетке, как принимать, «поддерживает…» с дисклеймером. Обязательная сноска: «БАД не является лекарственным средством. Перед применением проконсультируйтесь со специалистом.»
- **Висячие предлоги**: после коротких предлогов и союзов (в, к, с, у, о, и, а, на, по, за, из, от, до, не, для, при…) ставьте неразрывный пробел. Тексты из данных оборачивайте в `nbspDeep()`, строки — в `nbsp()` (`@/lib/typo`); в JSX-тексте добавляйте `&nbsp;` или символ U+00A0 вручную. Проверка: в тексте страницы не должно быть обычного пробела после такого слова.
- Названия: L.A.B Space (с неразрывным пробелом), Coral Club.
- Не выдумывайте цифры, отзывы и награды. Цены, составы и фото — только из каталога магазина.

## 7. Корзина, заказ, реферальные ссылки

- Корзина лежит в `localStorage` (`@/lib/cart`), заказ оформляется в магазине coralclub.ru: корзина передаётся ссылкой `shop_basket.php?REF_CODE=…&user=…&f=y&<артикул>=<кол-во>` (`friendBasketUrl` / `shopBasketUrl`). Покупатель не регистрируется, цены клубные.
- Уникальные реферальные ссылки дистрибьюторов: `src/lib/friend.ts` (описание: `handoff/friend-club.md`, если файла нет, смотрите код): `?ref=<REF_CODE>`, дистрибьютор определяется запросом к магазину и запоминается на 30 дней.
- Свой чек-аут поверх API магазина (`src/components/landing/LandingCheckout.tsx`) — тестовый стенд, работает только через локальный прокси `npm run dev:proxy` (http://localhost:3200). Создаёт настоящие заказы, поэтому «Перейти к оплате» нажимает только человек.

## 8. Формы и заявки

- `LeadForm`: имя, телефон (маска `+7 (999) 999-99-99`), e-mail (необязательно). Поля без подписей, подсказка видна сразу; рамка активного/неполного поля темнее, без красного.
- Заявки уходят в Google Таблицу через Apps Script (`scripts/leads/`, адрес в `src/lib/leads.ts`): имя, телефон, email, источник, четыре UTM-поля, адрес страницы. Источник: `?source=` или `utm_source_utm_medium`.
- Отдельная ссылка на форму: `/landing/consultation/?utm_source=offline&utm_medium=qr&utm_campaign=…&utm_content=…`.
- В аналитику персональные данные не передавать.

## 9. Аналитика (GA4, счётчик `G-MLKGZ6XHY5`)

Правила разметки — из ТЗ № 327840. Всё подключено в `src/components/landing/Analytics.tsx` (кладётся в `layout.tsx` маршрута) и `src/lib/analytics.ts`.

- Каждому интерактивному элементу: `data-analytics-id="<латиница_через_подчёркивание>"` и, где нужно, `data-analytics-location="header | footer | home | catalog | product_card | cart | checkout"`. Клики по ссылкам/кнопкам превращаются в `link_click` / `button_click` сами.
- Блоки: `data-analytics-section`, `data-analytics-promo` (+ `-name`, `-creative`, `-slot`), `data-analytics-list` (+ `-name`, `-items`), карточка — `data-analytics-item`, `data-analytics-index`.
- События корзины (`add_to_cart`, `remove_from_cart`, `view_cart`, `begin_checkout`) и `view_item`, `select_item`, `view_item_list`, `view_promotion` уже работают, если товар есть в `src/lib/analyticsRu.ts` (`itemFor`). Новые артикулы добавьте туда и в `LANDING_BONUS`.
- С localhost события только печатаются в консоль (`[analytics] …`) и лежат в `window.dataLayer`; `?ga=on` включает настоящую отправку (DebugView), `?ga=off` выключает. Не отправляйте тестовые события в боевой счётчик.
- Подробная карта событий: `handoff/analytics-events.md` (если файла нет, посмотрите `Analytics.tsx`).

## 10. UTM (из гайда «Правила utm-разметки»)

`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`. `utm_campaign` = `{номер_товара}_{название}_{source}_{medium}_{type}_{campaign}_{geo}`, слова внутри блока через дефис, блоки через подчёркивание; нет товара — `all_all`. QR-коды: `utm_source=offline`, `utm_medium=qr`, `type` = `flyer | booklet | banner`; `utm_content` = дата ГГГГММДД + краткое название. Ссылку на печать сокращать (bitly) и ссылаться на домен `coralclub.ru` без префикса страны.

## 11. Чек-лист перед сдачей

- [ ] Только токены и готовые компоненты, цвета не «зашиты»; контраст текста достаточный
- [ ] Проверено на 390px и на 1280px+ (скриншоты обоих), нет горизонтальной прокрутки
- [ ] Заголовки: прямой шрифт + курсивный акцент; один главный призыв на экран
- [ ] Нет медицинских обещаний, есть сноска про БАД; цены и составы из каталога
- [ ] Неразрывные пробелы после предлогов; `Accent` не разрывает смысл
- [ ] Интерактивные элементы с `data-analytics-id`; события видны в консоли; PII в аналитику не уходит
- [ ] У страницы `robots: { index: false }`, пока лендинг не опубликован
- [ ] `npm run lint` и `npm run build` без ошибок; картинки лежат в `public/images/<имя>/` (webp), пути через `asset()`
- [ ] Анимации отключаются при `prefers-reduced-motion`

## 12. Чего не делать

- Не создавать новые цвета, шрифты, радиусы и тени.
- Не копировать компоненты «с изменениями»: расширяйте пропсами или оборачивайте.
- Не вставлять текст поверх фото на вебе, не обрезать фото товаров.
- Не писать клейм «лучший», «самый эффективный», «лечит», не обещать результат.
- Не хранить в репозитории ключи, токены и идентификаторы таблиц (он публичный).
- Не менять `src/app/landing/` и `src/app/friend/`, если задача про другой лендинг.

## Заготовка запроса

Собери лендинг «<название>» в `src/app/<имя>/`: <задача, аудитория, ключевое обещание, список блоков, продукты (артикулы), главный призыв>. Используй только готовые компоненты и токены, тексты по правилам раздела 6, разметку аналитики по разделу 9. В конце запусти `npm run lint` и `npm run build`, покажи скриншоты 390px и 1280px.
