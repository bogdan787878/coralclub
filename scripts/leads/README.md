# Заявки с /landing → Google Таблица

Форма просит только телефон. Заявка уходит в Google Apps Script, а он добавляет
строку в таблицу: дата, телефон, источник, четыре UTM-поля, адрес страницы.

1. Создайте Google Таблицу (пустую) → **Расширения → Apps Script**, вставьте
   содержимое `apps-script.gs`, замените `PASTE_SHEET_ID_HERE` на id таблицы
   (часть адреса между `/d/` и `/edit`), сохраните. Id в репозиторий не
   коммитим: он публичный, а в таблице телефоны.
2. **Начать развёртывание → Новое развёртывание → Веб-приложение**:
   «Выполнять от имени» — **я**, «Доступ» — **все**. Разрешите доступ к таблице.
3. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
4. Вставьте его в `LEADS_WEB_APP_URL` в `src/lib/leads.ts` (или задайте
   переменную `NEXT_PUBLIC_LEADS_ENDPOINT` при сборке) и запушьте в `main`.

Пока адрес не задан, форма работает, но заявка остаётся только в `localStorage`
браузера (`coralclub.leads.pending`), в таблицу она не попадёт.

Если таблица уже была с другими колонками, начните с нового листа: заголовок
записывается только в пустой лист.

Проверка после деплоя: откройте форму, отправьте заявку, строка должна
появиться в таблице за пару секунд. Скрипт отвечает без CORS, поэтому страница
не видит, принял ли он заявку («отправлено» значит «передано», а не
«строка записана»).

В таблице лежат телефоны посетителей: доступ к ней нужно оставить
**ограниченным** (только вам и тем, кому нужны заявки), не «всем по ссылке».
Скрипту это не мешает: он пишет от имени владельца.
